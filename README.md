# To-Do List (Pure JDBC) 🚀

Проект, написанный с нуля на чистом Java JDBC без использования фреймворков.
Цель — глубокое понимание работы с базой данных, транзакциями и архитектурными паттернами.

## 🛠 Технологический стек
- **Java 21**
- **PostgreSQL**
- **Maven** (сборка)
- **JDBC** (чистая реализация)

## 🏗 Ключевые фичи
- **Connection Pool**: Собственная реализация пула соединений на `ArrayBlockingQueue` и `Dynamic Proxy`.
- **Layered Architecture**: Разделение на `entity`, `dao`, `service`, `dto` и `util`.
- **Transaction Management**: Ручное управление транзакциями (`commit`/`rollback`).
- **Dynamic SQL**: Динамическое формирование запросов с защитой от SQL-инъекций.

## 📦 Структура пакетов
- `dao`: Data Access Object, взаимодействие с БД.
- `service`: Бизнес-логика приложения.
- `entity`: Отражение таблиц базы данных.
- `dto`: Объекты для передачи данных между слоями.
- `util`: Инфраструктурные классы (пул соединений, работа с пропертями).
